## 2. Komponen Komputer

### CPU (Central Processing Unit)
CPU adalah otak komputer yang bertugas memproses instruksi dan menjalankan perintah program.

### RAM (Random Access Memory)
RAM menyimpan data sementara yang sedang digunakan komputer. Data di RAM umumnya hilang ketika komputer dimatikan.

### Storage
Storage digunakan untuk menyimpan sistem operasi, aplikasi, dan file secara permanen, misalnya SSD dan HDD.

### Motherboard
Motherboard merupakan papan utama yang menghubungkan seluruh komponen komputer.

### GPU (Graphics Processing Unit)
GPU bertugas memproses grafis dan komputasi paralel tertentu.

## 3. Hubungan dengan Cybersecurity

- Membantu mengenali sumber masalah keamanan.
- Membantu memahami penggunaan sumber daya sistem.
- Menjadi dasar analisis keamanan komputer.
