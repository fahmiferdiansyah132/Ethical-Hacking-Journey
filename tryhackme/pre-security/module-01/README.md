## 1. Pengantar Keamanan Ofensif (Offensive Security)

Offensive Security adalah pendekatan keamanan siber yang menguji sistem, jaringan, dan aplikasi untuk menemukan kelemahan keamanan sebelum dimanfaatkan oleh penyerang.

Tujuannya:
- Menemukan kerentanan keamanan.
- Menguji ketahanan sistem.
- Mengidentifikasi risiko.
- Memberikan rekomendasi perbaikan.

Contoh pekerjaan:
- Penetration Tester
- Ethical Hacker
- Red Team Operator

## 2. Pengantar Keamanan Defensif (Defensive Security)

Defensive Security adalah pendekatan untuk melindungi sistem, jaringan, dan data dari ancaman siber.

Tujuannya:
- Mendeteksi aktivitas mencurigakan.
- Mencegah serangan siber.
- Memantau aktivitas jaringan.
- Menangani insiden keamanan.

Contoh pekerjaan:
- SOC Analyst
- Security Analyst
- Incident Responder

## 3. Perbedaan Offensive dan Defensive Security

| Offensive Security | Defensive Security |
|---|---|
| Menguji keamanan | Melindungi keamanan |
| Mencari kerentanan | Mendeteksi ancaman |
| Simulasi serangan | Memantau serangan |
| Red Team | Blue Team |

Keduanya saling melengkapi untuk meningkatkan keamanan organisasi.

## 4. Karier di Bidang Siber

Beberapa profesi dalam cybersecurity:

1. Ethical Hacker: menguji keamanan sistem dengan izin.
2. Penetration Tester: melakukan pengujian keamanan secara terstruktur.
3. SOC Analyst: memantau dan menganalisis ancaman keamanan.
4. Security Engineer: membangun dan mengelola sistem keamanan.
5. Incident Responder: menangani insiden keamanan.

## 5. Hal yang Saya Pelajari

- Memahami dasar keamanan siber.
- Mengenal Offensive Security dan Defensive Security.
- Memahami peran Red Team dan Blue Team.
- Mengenal beberapa profesi cybersecurity.
- Memahami pentingnya izin sebelum melakukan pengujian keamanan.

## 6. Kesimpulan

Offensive Security berfokus pada pengujian keamanan, sedangkan Defensive Security berfokus pada perlindungan dan deteksi ancaman. Keduanya memiliki peran penting dalam menjaga keamanan sistem informasi.
