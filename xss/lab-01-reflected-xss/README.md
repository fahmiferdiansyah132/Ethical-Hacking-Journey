# XSS - Reflected XSS

Platform: PortSwigger Web Security Academy

Lab: Reflected XSS into HTML context with nothing encoded

Status: COMPLETED

## Learning Objectives
- Memahami konsep Cross-Site Scripting (XSS).
- Mengenali reflected XSS.
- Memahami risiko input pengguna yang ditampilkan tanpa encoding aman.
- Memahami eksekusi JavaScript dalam konteks HTML.

## Tools
- Web Browser
- PortSwigger Web Security Academy

## Practice
Menggunakan kolom pencarian pada lab resmi untuk menguji apakah input dapat dieksekusi sebagai JavaScript.

## Learning Outcome
Berhasil menyelesaikan lab dan membuktikan reflected XSS melalui JavaScript alert.
