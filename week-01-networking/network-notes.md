# Week 01 - Networking Fundamentals
## 1. IP Address
Alamat yang digunakan untuk mengidentifikasi perangkat dalam jaringan.
## 2. MAC Address
Identitas fisik antarmuka jaringan.

## 3. DNS

Sistem yang menerjemahkan nama domain menjadi IP Address.

## 4. TCP dan UDP

Protokol komunikasi untuk mengirimkan data melalui jaringan.

## 5. Port

Nomor yang digunakan untuk mengidentifikasi layanan jaringan.
